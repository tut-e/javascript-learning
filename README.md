# Мой путь в JavaScript

Репозиторий создан для изучения языка программирования **JavaScript**, хранения практических задач, конспектов и учебных проектов. 

## 🎯 Мои цели
- [ ] Освоить базовый синтаксис JS (переменные, циклы, условия)
- [ ] Разобраться в тонкостях ООП и функционального программирования
- [ ] Понять работу с асинхронным кодом (Promises, async/await)
- [ ] Написать несколько самостоятельных мини-проектов

---

## 📂 Структура репозитория

*   `01-basics/` — Базовые темы (переменные, правила именования, комментарии, выражения и инструкции).
*   `02-data-types/` — Типы данных и методы работы с ними (в разработке).
*   `projects/` — Небольшие практические приложения (в разработке).

---

## 📔 Дневник прогресса

### Тема 1: Основы JS и синтаксис
- **Что изучено:** Разница между `let`, `const` и `var`, правила CamelCase, комментарии, а также отличия выражений (expressions) от инструкций (statements).
- **Практика:** Написан скрипт калькулятора скидок (`01-basics/discount-calculator.js`).
